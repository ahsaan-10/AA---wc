     STEP 2: DOM Analysis (Understanding the Website) 
Now the system must answer: 
“What kind of data exists on this site?” 
Algorithms used (NO AI yet) 
1. DOM Traversal 
• DFS / BFS over DOM tree 
• Collect: 
o Headings 
o Lists 
o Tables 
o Repeated blocks 
2. Repeated Structure Detection 
Same class + same child pattern + repeated count ≥ 3 
→ Treat as entity 
Example: 
<div class="faculty-card">...</div> 
<div class="faculty-card">...</div> 
→ Entity candidate: faculty

     STEP 4: Entity & Field Extraction (THIS IS THE CORE) 
Now system knows: 
Sector = Education 
It loads: 

--- PAGE 5 ---
blueprints/education.json 
 
Blueprint Example 
{ 
  "faculty": ["name", "designation", "department", "email"], 
  "students": ["roll_no", "name", "program", "semester"], 
  "courses": ["code", "title", "credits"] 
} 
 
How extraction works (real logic) 
For each detected entity: 
1. Look for labels near text 
2. Look for table headers 
3. Match against blueprint fields 
4. Fill what exists 
5. Leave missing fields nullable 
Example: 
<h3>Dr. Ali</h3> 
<p>Professor, CS</p> 
→ 
{ 
  "name": "Dr. Ali", 
  "designation": "Professor", 
  "department": "CS", 
  "email": null 
}
